# my-first-page

My first page — built for the SatsBoard Web Dev ladder (Web Dev 1, 2, 3).

Live site (GitHub Pages): https://jr-kenny.github.io/my-first-page/

## What's on the page

- **Web Dev 1** — a simple first page: who I am, what I build, hosted free on GitHub Pages.
- **Web Dev 2** — styling: dark theme, an original illustration (`photo.svg`), links and buttons to my GitHub, Prime Isles, and X.
- **Web Dev 3** — a working contact form (Formspree) plus a second page, `projects.html`, linked both ways.

## Before submitting to SatsBoard

Two placeholders must be replaced first:

1. **Lightning address** — in `index.html` and `projects.html`, replace
   `satsboard PLACEHOLDER-LIGHTNING-ADDRESS` with the real address, e.g.
   `satsboard jrkenny@getalby.com`.
2. **Formspree endpoint** — in `index.html`, replace
   `https://formspree.io/f/PLACEHOLDER-FORMSPREE-ID` with the real form endpoint
   (free, no card — create the form at https://formspree.io, copy the endpoint).
   Then test it by sending a message and screenshotting it arriving in the
   Formspree dashboard or inbox — that screenshot is part of the Web Dev 3 proof.
